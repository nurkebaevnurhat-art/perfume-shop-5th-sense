# Проверка 5th SENSE

## Инструменты

- Playwright уже установлен глобально: `createRequire('/opt/node22/lib/node_modules/')`,
  Chromium в `/opt/pw-browsers` (не запускать `playwright install`).
- Браузер теста не ходит в интернет через прокси → шрифты Google подаём через
  `scripts/fontroute.mjs` (curl + кэш), SheetJS — через `ctx.route(/cdnjs.../xlsx/)`
  из локального файла: cdnjs и jsdelivr из песочницы закрыты, а npm открыт —
  `npm pack xlsx@0.18.5` и взять `package/dist/xlsx.full.min.js`.
- Python-библиотеки (openpyxl) могут отсутствовать — `pip install openpyxl`.

## Имитация Vercel: `scripts/devserver.cjs`

```bash
PORT=8790 MODE=full ROOT=/путь/к/репо nohup node scripts/devserver.cjs > dev.log 2>&1 &
```
Режимы: `full` (Redis + Telegram + пароль `Пароль-5th`), `tg-only`, `no-admin`, `none` (404 на /api — демо).
Служебные адреса: `/__tg` (отправленные ботом сообщения), `/__calls` (все вызовы
Telegram API), `/__secret` (секрет webhook), `/__initdata` (подписанные данные
мини-приложения для пользователя 900). Webhook бота проверяется POST-запросами
на `/api/bot` с заголовком секрета.
Сервер кэширует модули — после правок в `api/` или `server/` перезапусти его.

## Что прогонять

- Заказ: самовывоз И курьер; ошибки формы; согласие; «Заказ принят» без плашки
  демо-режима (в full); сообщение в `/__tg`.
- Подмены: неверная цена из браузера, несуществующий товар, неверный статус,
  лимит 8 заказов, больше остатка (409).
- Админка: вход (неверный/верный пароль), заказы, смена статуса (тост о сообщении
  покупателю), тестовый заказ, вкладка «Данные» → бот (включить, пригласить, проверка).
- Каталог: загрузка таблицы с ошибкой (кнопка заблокирована, номер строки) и без;
  итоги предпросмотра; фото пачкой; «Скачать таблицу» → повторная загрузка без изменений;
  витрина: «Показать ещё», поиск брендов.
- Демо-режим: `python3 -m http.server` из корня — обычные сценарии; в консоли
  допустимы только 404 на `/api/status` и `/api/products`.
- Тёмная тема Android: Chromium с `--blink-settings=forceDarkModeEnabled=true`,
  `colorScheme: 'dark'` — страница должна остаться светлой.

## Ловушки окружения

- `pkill -f <шаблон>` убивает и твою собственную оболочку, если шаблон есть в её
  командной строке (exit 144). Останавливай так:
  `for p in $(pgrep -f 'node devserv'); do ps -o args= -p $p | grep -q '^node' && kill $p; done`
  — отдельной командой.
- `fullPage`-скриншоты дают чёрные полосы из-за появления элементов при прокрутке —
  это не баг сайта.
- Сеть наружу закрыта: живой сайт владельца отсюда не открыть — проси его
  проверить `https://<сайт>/api/status` и прислать скриншот.
