# Дизайн 5th SENSE

## Токены (`assets/css/style.css`, `:root`)

- Цвета: `--ink #0e0c0a` (тёплый чёрный), `--paper #f4efe6` (айвори), `--sheet #faf7f1`,
  `--paper-2 #e9e2d6`, `--gold #b08d5b` (матовое золото: линии, знаки),
  `--gold-soft #c9ad7d` (золото на чёрном), `--gold-deep #7a5c35` (золото для текста
  на светлом, `--brand`), `--ink-soft #6b6258`, `--error #a0402a`.
- Шрифты: `--ff-display` / `--ff-serif` = DM Serif Display (словесный знак и заголовки),
  `--ff` = Onest (текст). `font-synthesis: none`.
- `color-scheme: only light` (и meta в index.html) — не убирать.

## Компоненты и привычки

- `.line-link` (+ `--soft`, `--lg`, `--gold`) и `.hero-link` — все действия как
  подчёркнутый текст. Кнопки-прямоугольники пользователь просил убрать везде.
- Маркеры фильтров — ромбы (`.check-box` повёрнут на 45°), чипы — золотой текст,
  `.tag-chip` — подчёркнутые подписи.
- Фото: `--scene` (радиальный градиент) + `mix-blend-mode: multiply` +
  `.bottle-img { filter: brightness(1.07) contrast(1.02) }`; сетка `minmax(0, 1fr)` и
  `max-*: 100%`, чтобы высокие флаконы помещались.
- При `prefers-reduced-motion` переходы `none !important` (иначе `fit()` обрезал
  словесный знак).
- Тосты, статусы заказов, степпер корзины — компактные, в той же палитре.
